# Image-Search-App
🔎 A responsive Image Search App powered by the Unsplash API. Search for any image and get relevant results with descriptions. Supports up to 1000 unique, non-repetitive images with a modern, fast, and mobile-friendly design. Built using HTML, CSS, JavaScript, and API integration.
# 🔎 Image Search App

A responsive **Image Search App** that allows users to search for images using keywords and explore results fetched from the **Unsplash API**.

## ✨ Features

* 🔍 Search for images using keywords
* 🖼️ Fetch image results from the Unsplash API
* 📸 Display image previews with descriptions
* 🔄 Load more search results
* 📱 Responsive design for different screen sizes
* ⚡ Fast and simple user experience
